# ⏰ 마감지기 — 학년·반별 수행평가 달력 보드

2026 교내 SW 경시대회 출품작 (교육활동 개선 분야)

흩어진 수행평가 마감 정보를 우리 반 달력 하나로 모아 보여 주는 웹앱입니다.

## 기능

- 1~3학년 × 4개 반, 총 12개 반별 보드
- 달력에 수행평가 마감을 과목별 색상으로 표시, 날짜를 누르면 상세 보기
- 마감 임박순 목록과 D-day
- 과목 자유 추가: 정해진 목록 없이 미적분·대수 등 원하는 과목을 직접 추가
- 학생도 자기 반 보드에 수행평가 추가 가능 ('학생 등록 · 확인 전' 표시)
- 선생님 로그인 → 관리자 모드에서 학생 등록 일정 확인, 수정·삭제, 여러 반 동시 등록

## 실행 방법

1. `index.html` 파일을 브라우저(Chrome 권장)로 엽니다. 설치할 것은 없습니다.
2. 기본은 **데모 모드**입니다. 데이터가 이 브라우저에만 저장됩니다.
3. 오른쪽 위 "선생님 로그인" → 데모 비밀번호 `teacher2026` 입력 → 관리자 모드
4. "예시 데이터 채우기"를 누르면 모든 반에 가상 수행평가가 채워집니다.

## 실서비스 모드 (선택)

`index.html`의 `firebaseConfig`에 Firebase 프로젝트 설정값을 넣으면 모든 기기가 같은 보드를 실시간으로 공유하고, 선생님 로그인은 Firebase 인증(이메일/비밀번호)으로 바뀝니다. Firestore 보안 규칙 예시:

```
match /tasks/{id} {
  allow read: if true;                                   // 누구나 보기 가능
  allow create: if request.auth != null                  // 선생님은 자유롭게 등록
                || request.resource.data.verified == false; // 학생은 '확인 전' 상태로만 등록
  allow update, delete: if request.auth != null;         // 확인·수정·삭제는 선생님만
}
match /subjects/{id} {
  allow read, create: if true;                           // 과목 추가는 누구나
  allow delete: if request.auth != null;                 // 과목 삭제는 선생님만
}
```

## 주의

- 데모 모드의 선생님 비밀번호는 시연용이며 소스코드에 노출되어 있습니다. 실제 운영은 실서비스 모드를 사용해야 합니다.
- 예시 데이터는 모두 가상 데이터이며 개인정보를 포함하지 않습니다.

## 출처 및 라이선스

- 외부 라이브러리: 데모 모드에서는 사용하지 않음. 실서비스 모드에서만 Firebase JavaScript SDK(Apache License 2.0)를 CDN으로 불러옴
- 개발 과정에서 생성형 AI(Claude)를 활용했으며, 내역은 AI 활용 기록지에 기재함
